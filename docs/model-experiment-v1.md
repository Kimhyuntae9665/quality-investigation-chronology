# P10 pre-evaluation model experiment v1

Frozen on 2026-09-30 before any P10 Qwen call or evaluator-oracle inspection. This is a protocol, not a model result.

The existing loopback qwen3:4b may later propose source-bound assertions and questions. It is never given the evaluator oracle, denied-site rows, future rows, or the deterministic baseline's typed answer. Backend admission runs first. Use one serialized request under the shared GPU lock, no model download, bounded source context, one slot, think:false, truncate:false and shift:false only after verifying installed Ollama behavior. Record model digest, installed template hash, API version, scope/source hashes, selected source IDs, prompt/schema hashes, context/output budget, wall/server durations, GPU/RAM before/after, raw output and failure state. Context overflow is a failure.

Before evaluation cases, run exactly one **development schema/context preflight** at default PLANT-A/10:00 with admitted current-case sources. Ask for the inspection observation and at least one source-bound unresolved question. Required top-level fields are response_state, observations and questions; every proposed observation requires field, value, source_id and exact source quote. Empty observations on this evidence-present development case, null/empty source IDs, malformed JSON, timeout, unsupported source or wrong quantity are failures even with HTTP 200. The adapter verifies source permission, current revision and unique exact quote span before counting source linkage. Semantic support is reported separately: an exact quote is not a universal claim verifier. One documented schema/prompt revision is allowed using this development case only, then freeze before evaluator inspection.

After freeze and explicit GPU handover, process all nine packet evaluation scenarios once in declared order. Do not tune on their outputs. Keep raw failures. Report unsupported assertions, corrected quantities, unknown versus established status, denied-source exposure, exact quote validity and handoff readiness separately. CPU engineering tests, packet self-validation, and model quality counts have separate denominators. Related synthetic cases are not an independent external benchmark and do not establish real investigation performance.
